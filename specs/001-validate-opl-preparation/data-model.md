# Data Model: Preparação OPL validada

## Conventions

- Persisted documents include `schemaVersion`, `createdAt` and `updatedAt`.
- IDs are opaque strings generated by the main process.
- Paths persisted in snapshots are normalized relative paths; absolute paths stay in privileged runtime context or sanitized evidence.
- State fields are closed unions. Unknown evidence is explicit, never represented by missing booleans.
- SHA-256 values are lowercase hexadecimal and only marked verified after a complete successful stream.

## DeviceIdentity

Represents the selected physical/logical target across reconnects.

| Field                     | Type            | Rules                                               |
| ------------------------- | --------------- | --------------------------------------------------- |
| `deviceId`                | string          | Stable composite/fingerprint where platform permits |
| `displayName`             | string          | User-facing, not an authority for identity          |
| `mountPath`               | string          | Runtime-only absolute path                          |
| `platform`                | `win32          | darwin                                              | linux` | Required |
| `fileSystem`              | string          | Normalized; `unknown` allowed                       |
| `capacityBytes/freeBytes` | integer         | Non-negative                                        |
| `clusterBytes`            | integer/null    | Null means not verified                             |
| `maxFileBytes`            | integer/null    | Derived with evidence; null means unknown           |
| `readOnly`                | boolean/unknown | Evidence-backed                                     |
| `observedAt`              | datetime        | Required                                            |

Relationships: one device has many catalog snapshots, operations and readiness reports.

## OplProfile

Immutable description of an exact OPL binary.

| Field             | Type     | Rules                                                     |
| ----------------- | -------- | --------------------------------------------------------- |
| `profileId`       | string   | Unique                                                    |
| `versionOrCommit` | string   | Never only `latest`                                       |
| `variant`         | string   | Required                                                  |
| `officialUrl`     | URL      | Allowlisted official origin                               |
| `elfSha256`       | SHA-256  | Required                                                  |
| `obtainedAt`      | datetime | Required                                                  |
| `capabilities`    | object   | ISO, ZSO, USBExtreme, filesystems, naming/fragment policy |

State: `registered → selected`; update creates a new profile rather than mutating identity.

## CatalogScan

One read-only scan attempt.

| Field                      | Type          | Rules                             |
| -------------------------- | ------------- | --------------------------------- |
| `scanId`                   | string        | Unique                            |
| `deviceId/profileId`       | string        | Required references               |
| `status`                   | `running      | complete                          | failed | cancelled` | Only `complete` may become current |
| `startedAt/completedAt`    | datetime      | Completion nullable while running |
| `itemsSeen/itemsValidated` | integer       | Non-negative progress             |
| `provisionalItems`         | CatalogItem[] | Never current snapshot            |
| `failure`                  | Finding/null  | Controlled error                  |

Transitions: `running → complete|failed|cancelled`. Device identity change forces `failed`.

## CatalogSnapshot

Immutable result of a successful scan.

| Field                       | Type          | Rules                       |
| --------------------------- | ------------- | --------------------------- |
| `snapshotId`                | string        | Unique                      |
| `scanId/deviceId/profileId` | string        | Required references         |
| `capturedAt`                | datetime      | Required                    |
| `items`                     | CatalogItem[] | No truncation               |
| `findings`                  | Finding[]     | Device-level findings       |
| `supersedesSnapshotId`      | string/null   | Previous completed snapshot |

Only one current snapshot exists per device/profile pair. Failed scans retain evidence but never supersede it.

## FileIdentity

Identity used to invalidate cached evidence and manual overrides.

| Field                 | Type          | Rules                            |
| --------------------- | ------------- | -------------------------------- |
| `deviceId`            | string        | Required                         |
| `relativePath`        | string        | Normalized, confined             |
| `sizeBytes`           | integer       | Non-negative                     |
| `modifiedAt`          | datetime/null | Platform-dependent               |
| `structuralSignature` | string/null   | Lightweight parser-derived value |
| `sha256`              | string/null   | Only after full on-demand hash   |

Change in path, size or structural signature invalidates manual Game ID. Hash, when present, is strongest identity evidence.

## CatalogItem

Logical game or unknown candidate. USBExtreme parts form one item.

| Field                 | Type                  | Rules                                         |
| --------------------- | --------------------- | --------------------------------------------- |
| `itemId`              | string                | Snapshot-local opaque ID                      |
| `kind`                | `game                 | unknown`                                      | Required      |
| `title`               | string/null           | Derived or absent                             |
| `gameId`              | normalized ID/null    | `AAAA_000.00`                                 |
| `gameIdSource`        | `iso                  | zso                                           | filename      | ul-cfg   | manual   | none`    | Required |
| `mediaType`           | `DVD                  | CD                                            | not-verified` | Required |
| `installFormat`       | `ISO                  | ZSO                                           | USBExtreme    | unknown` | Required |
| `relativePath`        | string                | Logical path; USBExtreme references its entry |
| `files`               | FileIdentity[]        | One or more                                   |
| `totalBytes`          | integer               | Sum for multipart                             |
| `structuralIntegrity` | VerificationState     | Required                                      |
| `hashState`           | `not-calculated       | running                                       | verified      | failed   | stale`   | Required |
| `fragmentation`       | FragmentationEvidence | Required                                      |
| `art`                 | ArtState              | Required                                      |
| `compatibility`       | VerificationState     | Relative to profile                           |
| `classification`      | `ready                | warning                                       | invalid`      | Derived  |
| `findings`            | Finding[]             | Reasons/evidence                              |

Classification: `invalid` for incomplete/inconsistent/unsafe; `warning` for recognized non-blocking or unverified conditions; `ready` only when structural and required compatibility/contiguity checks pass.

## ManualGameIdOverride

| Field                   | Type          | Rules                     |
| ----------------------- | ------------- | ------------------------- |
| `overrideId`            | string        | Unique                    |
| `deviceId`              | string        | Required                  |
| `fileIdentity`          | FileIdentity  | Snapshot at confirmation  |
| `gameId`                | normalized ID | Required                  |
| `createdAt/confirmedAt` | datetime      | Required                  |
| `status`                | `active       | invalidated`              | Derived on scan |
| `invalidatedReason`     | string/null   | Required when invalidated |

Transitions: `active → invalidated`; changed path, size, content/signature or device prevents automatic reuse.

## VerificationState and Finding

`VerificationState.status`: `passed|failed|not-verified`. It includes `checkedAt`, `method`, `evidenceRefs[]` and optional `reason`.

`Finding`: `code`, `severity` (`info|warning|error`), `scope`, `message`, `evidenceRefs[]`, `recoverable` and optional suggested action. Codes are stable contracts; messages are localizable.

### State derivation

| Layer        | States  | Derivation          |
| ------------ | ------- | ------------------- |
| Evidence     | `passed | failed              | not-verified`           | Direct result of one check; absence of a reference hash is `not-verified`, not corruption  |
| Catalog item | `ready  | warning             | invalid`                | Aggregates structural, compatibility, hash and fragmentation evidence for one logical game |
| Device       | `ready  | ready-with-warnings | requires-reorganization | incompatible`                                                                              | Aggregates item states, device capabilities and complementary validation according to FR-003 |

The three layers are distinct closed unions. UI labels may be localized, but persisted values and derivation rules remain canonical.

## FragmentationEvidence

| Field          | Type                 | Rules                               |
| -------------- | -------------------- | ----------------------------------- |
| `status`       | `verified-contiguous | verified-fragmented                 | not-verified` | Required |
| `method`       | string               | Adapter/version                     |
| `extentCount`  | integer/null         | Null if unavailable                 |
| `checkedFiles` | relative path[]      | Every ISO/ZSO/UL part when verified |
| `checkedAt`    | datetime             | Required                            |
| `reason`       | string/null          | Required for not-verified           |

## InstallationOperation

| Field               | Type              | Rules                                          |
| ------------------- | ----------------- | ---------------------------------------------- |
| `operationId`       | string            | Unique                                         |
| `deviceId/source`   | reference         | Required                                       |
| `selectedFormat`    | `ISO              | ZSO                                            | USBExtreme` | Capability-derived |
| `status`            | `planned          | staging                                        | validating  | promoting          | complete | rolling-back | failed | cancelled` | Journaled |
| `manifest`          | ManifestEntry[]   | Source, staging and final paths; sizes; hashes |
| `replacementItemId` | string/null       | Same Game ID replacement                       |
| `confirmation`      | confirmation/null | Required before replacement                    |
| `failure/recovery`  | object/null       | Controlled state                               |

Promotion rules: single files rename after final allocation validation; USBExtreme publishes parts before atomically replacing `ul.cfg`. Old installation remains until completion.

## ReorganizationOperation

Extends installation journal with immutable inventory, external backup identity/capacity, backup hashes, sequential rewrite groups and audit status.

Transitions: `planned → awaiting-confirmation → backing-up → backup-verified → rewriting → validating → complete`; any active stage may go to `failed`/`recovery-required`. No rewrite occurs before `backup-verified`.

## ArtAsset and ArtState

`ArtAsset`: Game ID, type (`ICO|SCR|SCR2|BG|LGO|COV|LAB|COV2`), source entry, source availability, staging path, final relative path, HTTP result, byte size, PNG signature result, SHA-256 and install result.

`ArtState.status`: `missing|cover-ready|partial|complete`. `availableTypes`, `installedTypes`, `existingTypes`, per-file errors and preferred cover are explicit. `complete` means every type advertised for that Game ID is installed.

## Pcsx2Profile and ValidationRun

`Pcsx2Profile`: executable version, architecture, SHA-256, sanitized origin, adapter ID and support status.

`ValidationRun`: run ID, device/snapshot/item/profile references, isolated datapath, BIOS hash+region only, memory-card clone hash, USB image hash, boot mode, timestamps, process result, checkpoints, artifact manifest and overall result.

Checkpoint fields: step, `passed|failed|not-verified`, actor `automatic|manual`, timestamp, reason and evidence hashes. PCSX2 approval requires all mandatory steps passed.

## ReadinessReport and HardwareSmokeTest

Report contains immutable references/snapshots of device, OPL, PCSX2, BIOS identity, games, hashes, fragmentation, art, logs/screenshots and limitations.

Independent results:

- `structural`: `passed|failed|not-verified`
- `pcsx2`: `passed|failed|not-verified|not-run`
- `hardware`: `passed|failed|not-verified|not-run`

`HardwareSmokeTest` records console model, adapter/device, OPL profile, device detection, art, fragmentation error observation, milestone and manual evidence. It never modifies prior structural or PCSX2 result.
